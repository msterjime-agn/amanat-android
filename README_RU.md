# Аманат — учёт передач Турция → Туркменистан

Android-проект первой версии 1.0.0. Минимальная версия Android — 8.0.

## Что реализовано

- Карточки денег, почты/посылок и комбинированных передач.
- Получатель, телефон, город, отправитель, сумма, валюта, количество мест, описание, примечание и исходное сообщение.
- Отдельные день списка, дата приёма, дата сообщения и даты фактических выдач.
- Порядковый номер начинается с 1 для каждого дня списка. Сохранённые номер и день списка закреплены за карточкой. Постоянный UUID исключает путаницу между одинаковыми номерами разных дней.
- Номер присваивается при сохранении в одной транзакции IndexedDB со счётчиком дня. Уникальный индекс защищает сочетание «день + п/н».
- Ручной ввод, приём текста через Android «Поделиться», предварительный разбор русских, турецких и туркменских подписей полей.
- Входящие из новых уведомлений IMO: включаются пользователем в настройках Android и отдельным переключателем в приложении. Поддержаны пакеты `com.imo.android.imoim` и `com.imo.android.imoimhd`. Полученный текст попадает на проверку, затем пользователь сохраняет карточку. Уведомления звонков и групповые сводки пропускаются.
- Статусы «Ожидает выдачи», «Выдано частично», «Выдано»; отдельные остатки денег и посылок.
- Частичные выдачи, имя фактического получателя, имя выдавшего, дата, история. Ошибочную выдачу можно отменить с причиной: запись остаётся в истории, остаток пересчитывается.
- Статистика за период и по городам. Денежные суммы учитываются целыми копейками/центами; валюты не складываются друг с другом. Архив не меняет обороты.
- Печать A4 через Android PrintManager и сохранение PDF средствами Android. Фильтры по статусу, периоду, городу, типу и валюте; телефоны, отправитель и графа подписи по выбору. Сохранённые дневные номера печатаются без перенумерации.
- CSV для Excel; резервная копия JSON всех карточек, истории, архива, настроек и счётчиков. Восстановление допускается в пустую базу, после проверки структуры и подтверждения количества записей.

## Сборка APK через GitHub

1. Создайте новый репозиторий, например `amanat-android`. Для исходного проекта подходит частный репозиторий.
2. Загрузите содержимое этого каталога в корень репозитория: `settings.gradle`, `build.gradle`, папку `app`, папку `tests`, `.github/workflows/android.yml` и остальные файлы. Сам ZIP не запускает сборку: файлы нужно распаковать. Если загружаете через сайт GitHub, убедитесь, что скрытая папка `.github` тоже загружена.
3. Положите файлы в ветку `main` или `master`. Workflow **Build Android APK** запустится автоматически при push. Его можно запустить и вручную из вкладки Actions → Build Android APK → Run workflow.
4. После успешного выполнения откройте **Artifacts → Amanat-Android-APK**. В архиве появится `Amanat-1.0.0-test.apk` или подписанный release APK и контрольная сумма SHA-256.
5. Скачайте APK на телефон и установите его. Для печати откройте «Списки», выберите записи и нажмите «Печать / PDF».

Workflow использует JDK 17, Gradle 8.11.1, Android Gradle Plugin 8.9.2, compile/target SDK 35. Gradle устанавливается action-ом, поэтому wrapper JAR в исходном архиве не требуется. Android SDK устанавливается на runner-е. Перед упаковкой запускаются проверки логики и Android Lint, после сборки проверяется подпись APK.

## Подпись для постоянных обновлений

Без настроенных signing secrets workflow собирает **тестовый debug APK**. Отладочный ключ на новом runner-е может измениться: такие сборки не предназначены для постоянных обновлений поверх предыдущей установки. Перед заменой тестовой установки сохраните резервную копию.

Для постоянной эксплуатации создайте один release keystore и сохраните его отдельно. Добавьте четыре секрета в Settings → Secrets and variables → Actions выбранного репозитория:

- `AMANAT_KEYSTORE_BASE64` — keystore, закодированный Base64;
- `AMANAT_STORE_PASSWORD` — пароль хранилища;
- `AMANAT_KEY_ALIAS` — имя ключа;
- `AMANAT_KEY_PASSWORD` — пароль ключа.

После настройки собирается `Amanat-1.0.0.apk`, подписанный постоянным ключом. Версия APK увеличивается по номеру запуска workflow. Ключи, пароли и данные клиентов не следует коммитить. `.gitignore` исключает файлы keystore и каталоги сборки.

## Работа с IMO

На экране «Ещё» нажмите «Подключить IMO», предоставьте системный доступ к уведомлениям и включите сбор. Аманат не запрашивает пароль IMO. Текст хранится в собственной локальной базе входящих. Новые уведомления должны быть включены в самом IMO; скрытый в уведомлении текст приложение получить не сможет.

Автоматический сбор ограничен группой с точным названием **Amanat** (регистр не важен). Требуется отдельное название беседы; общий заголовок может содержать имя отправителя и для выбора группы не используется. На Android 9+ требуется также признак группового чата; неоднозначное уведомление не сохраняется. Подробности исправления после сборки №6, тестовые случаи и проверка на телефоне: [docs/IMO_FILTER_REVIEW_RU.md](docs/IMO_FILTER_REVIEW_RU.md).

Старую переписку, фотографии и голосовые сообщения этот механизм не считывает. Для старых текстов используйте копирование/вставку или системную команду «Поделиться», если она доступна в установленной версии IMO. Парсер предлагает поля только по явным подписям/валютам. Несколько сумм и отсутствующие поля отмечаются для ручной проверки.

Резервная копия JSON включает сохранённые карточки. Ещё не обработанные уведомления IMO хранятся отдельно на телефоне и в JSON не включаются.

## Печать

Списки создаются в альбомной ориентации A4. При выборе диапазона по выдаче столбец «Выдано за период» учитывает только активные выдачи внутри диапазона; текущий остаток выводится отдельно. Одна передача с несколькими выдачами представлена одной строкой. Для принтера нужна подходящая Android-служба печати и доступное подключение; можно сначала сохранить PDF и распечатать с компьютера.

## Хранение данных

Сохранённые карточки находятся в IndexedDB Android WebView в закрытом каталоге приложения. Входящие уведомления — в SQLite. Разрешение на Интернет отсутствует: интерфейс загружается из APK через локальный перехват HTTPS-запросов, обращения к сети блокируются. JSON/CSV сохраняются через системный выбор файла. Автоматической синхронизации между телефонами в этой версии нет.

Перед удалением приложения, очисткой его данных или переносом на другой телефон сохраните резервную копию через «Ещё». Восстановление сохраняет номера, даже если карточки были архивированы. Номер дня не переиспользуется после архивации.

## Проверки и состояние

Локально выполнены 16 автоматических тестов логики расчётов, дат, парсинга, резервных копий, CSV и HTML печати; проверен синтаксис JavaScript, XML и YAML. Проверка браузерного интерфейса включает создание карточек на разные дни с п/н 1, частичную выдачу 40 из 100 USD и согласование остатка 60 USD со статистикой.

Сам Android-проект в текущем окружении не компилировался: Android SDK отсутствует. Установка, системная печать и фактические уведомления IMO требуют проверки на телефоне после успешной GitHub-сборки. При создании этого архива запуск workflow ещё не выполнялся.

Локальные тесты при установленных Node.js и JDK 17: `node --test tests/*.test.mjs`. Эта команда также компилирует и проверяет Java-фильтр IMO без Android SDK; отсутствие JDK считается ошибкой теста.
